# RDE / UREM Project Overview

## Vision

The Recognition Disequilibrium (RDE) and Under-Recognized Exceptionality Modeling (UREM) project is a long-term scientific research program focused on discovering, explaining, and validating places that possess exceptional underlying characteristics but receive less recognition than would be expected.

The project combines geospatial science, applied mathematics, spatial statistics, machine learning concepts, and scientific software engineering into a unified computational framework.

Rather than serving as a single research paper or GIS workflow, the project is intended to become a reusable scientific methodology, an extensible software framework, and eventually the foundation for an interactive research platform.

---

## Core Research Questions

The framework seeks to answer questions such as:

- Why do exceptional places become under-recognized?
- Can recognition disequilibrium be measured mathematically?
- Can expected recognition be estimated from observable characteristics?
- Can statistically significant under-recognized landscapes be identified?
- Can independent datasets validate these discoveries?

---

## Scientific Components

The project currently consists of several major scientific components.

### Physical Exceptionality

Measures the intrinsic characteristics of a landscape independent of human recognition.

### Expected Recognition

Models the level of recognition expected given physical, contextual, and opportunity-related characteristics.

### Recognition Disequilibrium (RDE)

Quantifies the difference between expected recognition and observed recognition.

### Validation Framework

Evaluates discoveries using independent external datasets and spatial null models.
