# KB-0004 — GNIS Subgroup Experiments

**Status:** Accepted

**Date:** 2026

---

# Problem

Initial validation using the complete GNIS natural-feature dataset produced weak or contradictory evidence.

At first glance this suggested that Recognition Disequilibrium might not correspond to named geographic features.

However, the complete GNIS dataset combines many fundamentally different classes of features, including:

- streams
- terrain
- bays
- beaches
- cliffs
- islands
- and many others

Treating these feature classes as a single validation target risked obscuring meaningful relationships.

---

# Decision

Rather than abandoning GNIS as a validation source, the dataset was partitioned into scientifically meaningful subgroups.

Separate experiments were conducted for:

- coastal landforms
- hydrology
- terrain
- distinct natural features

Each subgroup was evaluated independently using the same validation framework.

---

# Rationale

Different classes of natural features represent different recognition processes.

For example:

- coastal landforms often correspond to destinations, scenic viewpoints, or protected landscapes

whereas

- streams and terrain names frequently represent cartographic reference features rather than public recognition.

Separating these feature classes allowed the framework to distinguish between fundamentally different forms of geographic naming.

---

# Scientific Findings

The subgroup experiments revealed a clear pattern.

Strong support:

- coastal landforms

Mixed support:

- distinct natural features

Inverse or weak support:

- hydrology
- terrain

These findings demonstrated that the original hypothesis required refinement.

---

# Theory Refinement

The project no longer claims that Recognition Disequilibrium aligns with arbitrary named geographic features.

Instead, the current evidence supports a more precise hypothesis:

> Recognition Disequilibrium hotspots preferentially occur near independently recognized coastal recognition features rather than arbitrary geographic features.

This represents one of the most important theoretical refinements in the project's history.

---

# Consequences

The subgroup experiments strengthened the scientific credibility of the framework.

Rather than forcing agreement across all datasets, the methodology allowed contradictory evidence to refine the underlying theory.

Future validation datasets should therefore be selected according to the recognition processes they represent rather than simply their geographic content.

---

# Long-Term Impact

This decision permanently changed the project's validation philosophy.

Future work emphasizes:

- independent recognition datasets
- theoretically meaningful validation targets
- hypothesis refinement through evidence

rather than maximizing apparent agreement across unrelated geographic datasets.
