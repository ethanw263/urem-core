# KB-0003 — Oregon Validation

**Status:** Accepted

**Date:** 2026

---

# Problem

The earliest versions of the RDE framework were developed and tested primarily within California.

Although these results demonstrated that the framework could identify plausible under-recognized locations, they did not establish whether the methodology generalized beyond the original study region.

A scientifically credible framework requires validation using independent geographic regions.

---

# Decision

The Oregon Coast was selected as the first independent validation study region.

Rather than reproducing California exactly, Oregon provided a new geographic setting with different physical characteristics, patterns of tourism, conservation history, and recognition dynamics.

---

# Rationale

Oregon was chosen because it offered:

- a continuous coastal landscape
- abundant independent validation datasets
- high environmental diversity
- different recognition patterns from California
- an opportunity to evaluate generalization

The objective was not simply to replicate California, but to determine whether the underlying Recognition Disequilibrium methodology remained meaningful under new geographic conditions.

---

# Scientific Outcomes

The Oregon validation phase produced several major advances.

The project developed:

- external validation datasets
- spatial null-model validation
- experiment abstraction
- evidence synthesis
- experiment registry
- provenance tracking
- configuration-driven experiments

The Oregon phase therefore strengthened both the scientific methodology and the software architecture.

---

# Lessons Learned

Validation demonstrated that:

- some independent datasets strongly supported the framework
- others did not

These mixed outcomes improved the theory rather than weakening it.

Negative evidence helped refine the scientific hypothesis and identify which external datasets genuinely represented recognition processes.

---

# Consequences

Oregon transformed the project from a regional proof-of-concept into a generalizable scientific framework.

Future expansion to Washington, California back-porting, and inland study areas now follows an established validation methodology rather than requiring new framework development.

---

# Long-Term Impact

The Oregon validation phase established the project's philosophy of independent external validation.

Every future study region should be evaluated using reproducible experiments, independent datasets, and spatial null models rather than qualitative assessment alone.
