# Project History

## Purpose

This document records the evolution of the RDE / UREM project.

It is not a changelog. It is a research history.

Its purpose is to preserve the major intellectual, methodological, and architectural milestones that shaped the project.

## Major Evolution

### UREM

The project began as an effort to identify under-recognized exceptional places using geospatial indicators of physical potential and observed recognition.

### Recognition Disequilibrium

The framework evolved from a suitability-style model into a theory of Recognition Disequilibrium.

The central question became:

> Why do some exceptional places receive less recognition than expected?

### Oregon Validation

The Oregon coast became the first major external validation environment.

Validation experiments showed strong support from:

- PMEP Estuaries
- PAD-US Protected Areas
- GNIS Coastal Landforms

They also showed inverse or non-supportive evidence from:

- GNIS Hydrology
- GNIS Terrain

This refined the theory.

The project no longer claims that RDE hotspots occur near arbitrary named geographic features.

Instead, the current evidence suggests:

> RDE hotspots preferentially occur near independently recognized coastal recognition features rather than arbitrary geographic features.

### Experiment Framework

The project transitioned from one-off scripts into a reusable experiment framework.

This included:

- validation engine
- null model engine
- experiment abstraction
- YAML configuration
- registry
- discovery
- synthesis
- provenance
- CLI
- automated tests

### Documentation Platform

The project began transitioning into a documented scientific platform using MkDocs.

The long-term goal is a searchable documentation website that preserves theory, software architecture, methodology, and future research plans.

## Current Phase

The project is currently in Framework Consolidation.

The goal is to strengthen reproducibility, documentation, testing, architecture, and maintainability before expanding to additional regions and validation datasets.
