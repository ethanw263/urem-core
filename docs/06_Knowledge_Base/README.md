# RDE / UREM Knowledge Base

The Knowledge Base preserves the reasoning behind the RDE / UREM framework.

Regular documentation explains how the framework works.

The Knowledge Base explains why the framework was built this way.

It records:

- major scientific decisions
- mathematical rationale
- validation lessons
- rejected hypotheses
- architectural choices
- future research ideas
- commercialization and platform concepts

This section exists so the intellectual history of the project is not lost across chats, scripts, experiments, and future development phases.

## Sections

- `Decision_Log/` — major scientific and architectural decisions
- `Research_Notes/` — evolving scientific notes and open questions
- `Future_Ideas/` — long-term theory, software, platform, paper, and product ideas
