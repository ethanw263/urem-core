Theory Audit Decision — Spatial Recognition Theory Must Be Falsifiable Through Added Value, Mechanism Separation, Persistence, Geometry, and Transfer:
The theory survives only if spatial recognizability adds explanatory value beyond suitability, if mechanisms such as shadowing, transmission failure, inertia, and allocation failure can be separated, if recognition structures persist under perturbation, if recognition geometry improves explanation beyond ordinary distance or accessibility, and if the framework transfers across place-based domains. Otherwise, the framework collapses into existing GIS methods.
