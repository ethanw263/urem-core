Axiomatic Compression Decision — Three-Primitive Core:
The RDE framework can provisionally be compressed to three primitive objects: a structured recognition system R, latent recognition potential Φ, and realized recognition R. Allocation, expected recognition, disequilibrium, equilibrium, geometry, kernels, sources, sinks, shadowing, reinforcement, phase states, stability, and functionals should be treated as derived objects unless future analysis proves one of them irreducible. This compression is valid only if R is defined as a sufficiently structured system capable of inducing recognition operators, geometries, dynamics, and admissible states.
